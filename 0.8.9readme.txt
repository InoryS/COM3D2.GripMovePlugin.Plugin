GripMovePlugin v0.8.9
(Additional HTC VIVE Controller / Oculus Touch plugin)

[Features]
This plugin adds an additional control mode "DIRECT" for HTC VIVE controller / Oculus Touch.
For Oculus Touch, see [Oculus Touch] section.  

"DIRECT" mode is activated by holding "Application Menu" button 1.5 seconds (now configurable).
After that the mode is activated by using "Application Menu" button.

While in "DIRECT" mode, you can: 
 - Move camera by VIVE controller directly.
  While holding "Trigger" (or "Grip") button of the VIVE controller, you can move yourself by moving your controller.

 - Floating GUI Screen 
  GUI screen can be grabbed by holding "Grip" (or "Trigger") of the VIVE controller, then be moved and placed anywhere you want.
  You can set cursor position by touching the GUI screen by VIVE controller, or moving cursor by touching the VIVE Touch Pad. 
  You can click by clicking the VIVE controller Touch Pad (Left Side: Left button, Right Side: Right button).

 - Move to Head
  When you press Move to Head button (Touchpad or the other configured) while holding the Move Camera button (Trigger or Grip)
  The camera is moved to the man's head position (like first person).    

 - Handy Yotogi Command tool - DIRECT(com) mode (new in v0.4)
  Pressing Menu button with holding the Grip button (or other configured button), the mode is toggled between DIRECT / DIRECT(com) mode.
  You can select Yotogi command by touchpad (x-axis swipe) and run the command by pressing down the Touchpad.
  Even while in this mode, you can directly touch GUI screen to select item and click it, however, you may not be able to move mouse cursor by touchpad.

 - IK (Inversive Kinematics) tool for official Photo mode (new in v0.5.0)
  In the official Photo mode, by pressing Menu button with holding the Grip button (or other configured button), the mode is toggled between DIRECT / DIRECT(IK) mode.
  You can grip the IK marker and move it to pose your maid as you want.
  The IK marker will be hidden if you click the Touchpad in this mode. 
  The positions you can move are, Finger, Hand (wrist), Forearm, UpperArm, Clavicle, Neck (rotation), Spine-Spin1a (rotation), Thigh (rotation), Calf and Foot.  
  (new in v0.5.5) Added _IK_ node handles for Maid item position/rotation control. Those handles are shown as green sphere.
  (new in v0.6.0) Added a new plugin CM3D2.PhotoIKBase.Plugin that enables loading saved XML data in the non-VR version Photo mode.

  [Note for Official "Pose Editor"]
  In this version, the GripMovePlugin respects the official Pose Editor configuration.
  When you move IK node, the "Pose Edit" is automatically turned "On".

  [CAUTION]
  In this mode, I added additional save data which includes IK node position/rotation information, into the Photo save data (which saved into <CM3D2>/PhotoModeData/SaveData).
  The saved Photo data can be opened with the vanilla CM3D2, however, it is recommended to use separated save data for this mode.

 - Maid Direct Touch framework (new in v0.6.0)
  Framework code is added to develop direct touch event handling MOD for VIVE VR.
  Please see CM3D2.VIVEDirectTouchAddon.Plugin as the sample of the implementation.

  Touch size can be adjusted by adding the following settings into the "gripmoveplugin.ini" file. 
   DirectTouchTool_Size_VAGINA=0.03
   DirectTouchTool_Size_ANAL=0.03
   DirectTouchTool_Size_HIP=0.12
   DirectTouchTool_Size_MUNE=0.12
   DirectTouchTool_Size_HAIR=0.13
   DirectTouchTool_Size_MOUTH=0.03
   DirectTouchTool_Size_EYE=0.04
   DirectTouchTool_Size_HARA=0.1
   DirectTouchTool_Size_KATA=0.08
   DirectTouchTool_Size_HAND=0.08
   DirectTouchTool_Size_MOMO=0.1
   DirectTouchTool_Size_FOOT=0.08

 - VIVE Model Replace Tool (new in v0.6.1)
  While in DIRECT mode, you can swtch the VIVE model by pressing Touchpad with holding the Grip button.
  By default, you can use Hand (extracted from mbody in runtime) as well as Pink Vibe (as a sample of custom model).
  Using "gripmove_model.ini" you can configure the detailed setting. 
   - Hand<xxx> - Configure Hand color, position and rotation. 
  You can add any of custom models (CM3D2 .model format) in the config file. 
   - CustomModelCount  number of custom models.
   - CustomModel_<#>_ID ID of the model (should be identical)
   - CustomModel_<#>_Label Label of the model (not in use at this version)
   - CustomModel_<#>_Model .model file name (CM3D2 .model format)
   - CustomModel_<#>_Pos_X, Pos_Y, Pos_Z  Adjustment of position of the model
   - CustomModel_<#>_Rot_X, Rot_Y, Rot_Z  Adjustment of rotation of the model
   - CustomModel_<#>_HidePointer  Set True if you want to hide DIRECT mode pointer (sphere) and mode text label
   - CustomModel_<#>_EnabledHand  Set "L", "R" or "LR" if you enable the model only left hand, only right hand or both hands.

 - Runtime Configuration menu (new in v0.7.0)
  You can now set the following configuration at runtime through new menu.
     Disable/Enable all move functionality by trigger (or grip).
     Disable/Enable XZ rotation, and reset the rotation.
     Disable/Enable Y axis move.
     Disable/Enable Grab (official) when in DIRECT(IK) mode.
     Disable/Enable Grab (official) when in DIRECT mode (including IK mode).

[Oculus Touch]
Oculus Touch control is mapped as the followings:

VIVE controller        <-> Oculus Touch    

Application Menu       <-> Y button / B button
Trigger                <-> Index trigger
Grip                   <-> Hand (middle finger) trigger
Touchpad (click/touch) <-> X button /A button
Touchpad (Axis)        <-> Thumb stick

Pressing on the "Thumb stick" on Oculus Touch is mapped to mouse "right click".
Note: In v0.8.0, "DIRECT (com)" mode does not work.

[Configuration]
There are several configuration options available in "UnityInjector/Config/gripmoveplugin.ini" file.
 e.g. If you prefer to use Grip to move yourself and Trigger to move screen, configure as the following. 
 [GripMovePlugin]
 #Move self by grip, and move GUI screen by Trigger (v0.1.0)
 MoveSelfButton=Grip 
 MoveScreenButton=Trigger 
 MoveToHeadButton=Touchpad 
 
 #Bigger screen
 ScreenSize=0.4

 #Unlock the x / z rotation (not recommend)
 LockRotateXZ=false

[How to install]
- Require UnityInjector.
- Place "UnityInjector" directory into your UnityInjector dir.

[How to uninstall]
- Delete "CM3D2.GripMovePlugin.Plugin.dll"
- Delete "CM3D2.PhotoIKBase.Plugin.dll"
- Delete "Config/gripmoveplugin.ini"
- Delete "Config/photoikbaseplugin.ini"
